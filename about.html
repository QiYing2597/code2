关于我 and 这个博客的创建思路

你好，我是一名前端web开发专业的学生

从 2024 年开始接触前端开发，从最初的 HTML/CSS 到如今的 React、TypeScript、 构建工具链，领悟到了 Web 技术的飞速发展。

这个博客是我记录学习笔记、分享实战经验的地方。每一篇文章都力求清晰、实用， 希望能帮助到走在相同道路上的开发者。

我相信，最好的学习方式是分享。如果你有任何问题或建议，欢迎通过联系页面 与我交流。

网站构建逻辑

概述
本博客是一个纯静态前端网站，基于 HTML5 + CSS3 + JavaScript 构建， 部署在 GitHub 上。

技术栈

HTML590%
css380%
JavaScript75%
GitHub Pages70%
  • HTML5——构建网页结构
  • css3——flex布局，渐变，响应式设计
  • JavaScript——轮播图逻辑，原生DOM操作
  • GitHub Pages——免费静态托管

页面结构

由导航栏，轮播图，卡片网络的多个结构组成

导航栏

导航栏由5个链接构成，并分别指向博客的每个模块。当点击某个模块时会跳转到相应模块

轮播图

通过css来实现对图片的滑动效果，并且能通过鼠标点击来实现滑动

设计思路

通过我的构思，并且运用ai技术使得页面设计得简洁明了，色调温和不刺眼，运用响应式设计使布局自动适配。
